# 실험 3o: 연속 백분위 주석과 겹치지 않는 구간에서의 층위 대비 (2026-10-21 작성, 2026-10-21 결과 보기 전 고정)

> **고정(2026-10-21, 사용자 확인)**: "구간수는 본문에서 나눈 범위를 확인하고 맞춰줘. 그리고 새 GWAS도 포함하자". 본문의 층위 지도 역치(주 지도 5 %, 역치 민감도 1 %·0.5 %·0.1 %)에 맞춰 겹치지 않는 네 구간(0–0.1 %, 0.1–0.5 %, 0.5–1 %, 1–5 %)으로 정했다. 초안의 5–20 % 구간은 본문에 없는 범위라 뺐다. 3n의 새 GWAS 다섯 형질을 기술 결과로 넣는다.

## 배경

- 사용자 결정(2026-10-21): 분석 1(3n)에 이어 이 분석까지 마친 뒤 원고에 함께 반영한다.

## 사후성 명시
- 이미 본 것: 3c–3n의 모든 결과. 특히 포함 관계 역치 결과(3g, 3m M2: CAGE − DNase 부호가 모든 역치에서 같은 형질 7개, 바뀌는 형질 7개)를 보고 이 분석을 설계했다.
- 아직 보지 않은 것: 연속 주석과 구간 주석의 모든 S-LDSC 결과.

## 주석 (o01; 3g u01과 같은 점수·백분위)
- 점수: 계통 g(골수계, 뇌 조직, 림프계, 간, 결합조직) × 층위 m(CAGE, DNase, H3K27ac) 칸마다 전체 트랙 |효과| 최댓값(3d L5와 같은 트랙 묶음) → 대상 SNP 5,828,323개 안의 백분위 R(0–1, 동점은 평균 순위; 3g와 같다).
- **연속 주석 `C_{g}_{m}`** = R. MAF < 5 % 또는 Atlas 값이 없는 SNP는 0(다른 주석과 같다).
- **구간 주석 `B{k}_{g}_{m}`** (서로 겹치지 않음):
  - B1 = 상위 0–0.1 % (R ≥ 0.999)
  - B2 = 상위 0.1–0.5 % (0.995 ≤ R < 0.999)
  - B3 = 상위 0.5–1 % (0.99 ≤ R < 0.995)
  - B4 = 상위 1–5 % (0.95 ≤ R < 0.99)
  - 경계는 원고의 층위 지도 역치(0.1·0.5·1·5 %)와 같다. B1–B4를 합치면 주 지도의 5 % 주석이고, B1은 3g의 0.1 %, B1 + B2는 0.5 %, B1 + B2 + B3은 1 % 주석과 같다.
- 확인(어긋나면 멈춘다): 구간을 합친 주석의 sd가 3d L5(B1–B4), 3g L0p1(B1), L0p5(B1–B2), L1p0(B1–B3)과 같다(차이 < 1e-9).
- LD 점수: 3g와 같은 l2 호출(1 cM, 1000 Genomes EUR GRCh38, HapMap3 회귀 SNP). 주석 75개(5 계통 × (연속 3 + 구간 12)).
- 기술: 같은 계통 안 층위 간 연속 주석 상관, 구간별 Jaccard, 기준선 보정 LD 점수의 VIF(3m M3와 같은 식).

## 모형 (o02; 3j 정렬 블록 실행기, 전체 트랙, 단일 실행)
| 모형 | 주석 (baselineLD v2.2에 더함) | 형질 |
|---|---|---|
| CONT | 연속 3층위 `C_{g}_{CAGE,DNASE,H3K27ac}` | 14형질(지도 11 + 검증 3), 자기 계통 |
| BIN | 구간 12개 `B{1,2,3,4}_{g}_{m}` (층위 3 × 구간 4) 동시 | 같음 |
- 원래 GWAS 14형질 × 2 = 28회(주). 형질과 계통은 주 지도와 같다.
- 3n의 새 GWAS 다섯 형질(키·BMI·조현병·양극성장애·LDL) × 2 = 10회(기술). 합계 38회.

## 대비와 판정
- 기준마다 c1 = CAGE − DNase, c2 = CAGE − H3K27ac τ\*와 95 % 신뢰구간. 기준은 연속(CONT), B1, B2, B3, B4다. 이미 있는 주 지도 5 %(전체 트랙)와 포함 관계 역치(0.1·0.5·1 %)도 나란히 보인다.

| | 내용 | 판정 |
|---|---|---|
| **O-H1 (주)** | CONT 모형에서 지도 형질 11개의 다변량 Q (c1, c2; 자유도 20, 공동 jackknife) | P < 0.05 → **"연속 주석에서도 형질 간 층위 이질성"** |
| **O-H2 (주)** | 형질마다 c1 부호가 전체 트랙 5 % 모형(T3all, 같은 전체 트랙 기준)과 같은지: CONT, B1, B2, B3, B4 (다섯 기준) | 다섯 모두 같은 부호 → **"방향 안정"**; 하나라도 다르면 **"기준 민감"**. 14형질 모두 분류하고 목록으로 보고한다. 같은 부호인 기준 수와 95 % 구간이 0을 벗어난 기준 수도 함께 적는다 |
| O-H3 | BIN 모형에서 구간별 Q (B1–B4 각각, 11형질) | 기술 |
| O-H4 | 사전 대비 세 개(뇌 형질 대 키, AD 대 키, IBD·RA 대 AD·단핵구 수)와 검증 대비를 CONT·B1–B4에서 | 기술 (추정치와 신뢰구간) |
| O-H5 | 새 GWAS 다섯 형질: CONT·B1–B4의 c1과 O-H2 분류(기준은 새 GWAS의 T3all, 3n), 새 GWAS로 바꾼 갱신 지도의 CONT Q | 기술 |

- B1(약 5,800 SNP)은 작아 SE가 크다. 그래도 원고의 역치와 맞추려고 넣었고, O-H2의 분류에 포함한다(사용자 결정에 따른 구간).
- VIF 규칙(3m M3와 같다): BIN 모형에서 층위 사이 VIF > 5인 계통의 구간 대비는 해석하지 않는다(값은 보고한다).

## 읽는 규칙
- O-H1·O-H2 결과로 원고의 역치 문단과 한계 셋째를 "어떤 형질의 차이는 기준과 관계없이 같은 방향이고, 어떤 형질은 기준에 따라 바뀐다"로 다시 쓴다. 방향 안정 형질과 기준 민감 형질을 이름으로 적는다.
- 보충 그림 S4를 확장해 포함 관계 역치와 이번 기준을 함께 보이거나, 새 보충 그림 하나를 만든다(결과를 본 뒤 정한다).
- 목표는 유의성이 아니라 안정성 서술이다. 따라서 기준별 P값으로 주장을 바꾸지 않는다.

## 한계 (미리 적음)
- 연속 백분위 주석은 대부분의 SNP(효과가 거의 0)에 값을 주므로, 상위 꼬리의 정보가 희석될 수 있다.
- 구간 경계(0.1·0.5·1·5 %)는 원고의 역치에 맞춘 하나의 선택이다. 상위 5 % 밖의 SNP는 보지 않는다.
- 네 구간 × 세 층위 = 12개를 함께 적합하므로 SE가 크고, 특히 작은 구간(B1, B3)이 그렇다.
