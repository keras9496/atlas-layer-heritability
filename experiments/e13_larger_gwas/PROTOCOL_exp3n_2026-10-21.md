# 실험 3n: 최신 대규모 GWAS로 층위 지도의 강건성 확인 (2026-10-21 작성, 2026-10-21 결과 보기 전 고정)

> **고정(2026-10-21, 사용자 확인)**: "UKB 포함판으로 가고, 활성도 조건화도 확인하도록 하자". 자료는 아래 표의 UKB 포함판이다. N-H6(활성도 조건화)을 포함한다. 이 시점까지 새 GWAS에서 본 것은 파일 머리글과 행 수뿐이다.

## 배경
- 교수님 피드백(2026-10-17) 추가 분석 1번: "주요 결과를 최근 대규모 GWAS에서 재현하십시오. … 우선 height, bipolar disorder, schizophrenia, BMI, LDL을 업데이트하고, 기존 lineage와 annotation, 주요 대조를 고정한 채 다시 분석하는 것이 효율적입니다. 최신 GWAS에 기존 참가자가 포함되어 있다면 '독립 재현'이라는 표현은 피하고, 최신 자료에서의 강건성 확인으로 보고해야 합니다." (같은 항목의 형질별 정보량 표는 3m M1에서 끝남.)
- 지금 지도에 쓴 다섯 형질의 GWAS: 키 Lango Allen 2010, BMI Speliotes 2010, 양극성장애 PGC 2011(N 16,731), 조현병 PGC 2014, LDL Teslovich 2010.

## 사후성 명시
- 이미 본 것: 3c–3m 전체 결과(주 지도, 검증, 견고성, 활성도 조건화).
- 아직 보지 않은 것: 새 GWAS 다섯 개의 모든 결과. munge(평균 χ² 포함)와 S-LDSC는 이 프로토콜을 고정한 뒤에만 돌린다. 고정 전에는 파일의 머리글과 행 수만 확인한다.

- 다섯 개 모두 원래 자료의 참가자를 포함한다. 그래서 결과는 **"더 큰 GWAS에서의 강건성 확인"**으로만 보고하고, "독립 재현"이라고 쓰지 않는다.
- UKB 포함: 새 키·LDL·BMI·양극성장애는 UKB를 포함한다. 검증 형질(골밀도, 총콜레스테롤, 호중구 수)과 단핵구 수도 UKB 자료다. 형질 간 공분산은 공동 jackknife(3j)로 반영한다. 검증 검정은 검증 형질만 쓰므로 바뀌지 않는다.
- PGC 자료는 PGC 이용 조건을 따른다(재배포 금지, 참가자 식별 시도 금지). 조현병 README의 "원 논문 출판 전 게놈 전역 분석 발표 금지"는 2022년 출판으로 해당하지 않는다.

## 요약통계 처리 (n01; 3f v04와 같은 절차)
- rsID, 효과·비효과 대립유전자, 효과 크기와 SE → Z = β / SE. SNV만, HapMap3 no-MHC SNP만, rsID 중복 제거 → `munge_sumstats.py --signed-sumstats Z,0`.
- 효과 크기: 키·BMI·LDL은 β, 조현병은 BETA(log OR), 양극성장애는 OR → log OR.
- LDL(GLGC) 파일에는 GC 보정 P(`pvalue_GC`)가 따로 있다. Z는 보정하지 않은 EFFECT_SIZE / SE로 만든다(LDSC 절편이 교란을 따로 잡으므로).
- 열 이름(머리글 확인, 2026-10-21): 키 RSID·EFFECT_ALLELE·OTHER_ALLELE·BETA·SE·N; BMI SNP·Tested_Allele·Other_Allele·BETA·SE·N; 조현병 ID·A1·A2·BETA·SE·NEFF(## 머리줄 건너뜀); 양극성장애 SNP·A1·A2·OR·SE·Neff_half; LDL rsID·ALT(효과)·REF·EFFECT_SIZE·SE·N.
- 표본 수: 열이 있으면 SNP별 값을 쓴다. 양적 형질은 N, 환자–대조군 형질은 유효 표본 수다(조현병 NEFF, 양극성장애 2 × Neff_half). τ\*는 N의 상수배에 영향받지 않는다.
- 유전체 빌드는 쓰지 않는다(rsID로 맞춘다).
- 확인: HapMap3 SNP의 80 % 이상이 남아야 한다. 아니면 멈추고 원인을 적는다.

## 모형 (n02; 고정된 것만 다시 적합, 새 주석 없음)
- 계통은 원래 지도와 같다: 키 = 결합조직(stromal), BMI·조현병·양극성장애 = 뇌 조직, LDL = 간.
- 모든 실행은 3j와 같은 설정이다: baselineLD v2.2, 정렬 블록 200개, 같은 회귀 가중치와 빈도 파일.
- (가) 층위 지도: 세 층위 동시 모형, 재추출 20회(3f T3_01–T3_20, 같은 단위와 seed) + 전체 트랙(T3all).
- (나) 계통 지도: 12개 계통 단일 주석 모형(그림 2와 같은 M1 주석) — 기술.
- (다) 활성도 조건화: 3l의 EA 모형(효과 3층위 + 활성도 3층위, 전체 트랙) — 기술.
- 새 실행: 5형질 × (21 + 12 + 1) = 170회.

## 가설과 판정 (α 사전 고정)
- 지도 형질 11개 중 다섯 개만 새 GWAS로 바꾼 "갱신 지도"에서 주 지도의 검정을 같은 방식(재추출 평균, 공동 jackknife)으로 반복한다.

| | 내용 | 판정 |
|---|---|---|
| **N-H1 (주)** | 갱신 지도 11개 형질의 다변량 Q (c1 = CAGE − DNase, c2 = CAGE − H3K27ac; 자유도 20) | P < 0.05 → **"형질 간 층위 이질성 유지"** |
| **N-H2 (주)** | 키가 들어간 사전 대비 두 개: 뇌 형질 4개(교육 연수·조현병·양극성장애·신경증) 대 키, AD 대 키 (c1, 양측, α 0.05/3) | 대비마다: 같은 부호이고 P < 0.017 → "유지"; 같은 부호이고 P ≥ 0.017 → "약화"; 부호 반대 → "반대". 셋째 대비(IBD·RA 대 AD·단핵구 수)는 바뀐 형질이 없어 값이 같다(보고만) |
| N-H3 | 새 GWAS 다섯 형질의 1위 층위, c1·c2, 분류 규칙(3f와 같음) | 기술. 다만 키는 미리 정한다: DNase 1위이고 c1 < 0(단측 P < 0.05)이면 "키의 DNase 쪽 위치 유지" |
| N-H4 | 형질마다 원래 대 새 GWAS의 τ\*, c1, c2, 표준오차(같은 참가자를 포함하므로 차이 검정은 하지 않음) | 기술 |
| N-H5 | 계통 지도: 고정 계통의 τ\*와 12개 중 순위 | 기술 |
| N-H6 | 활성도 조건화(EA): 자기 층위 효과 τ\*(키 DNase, 나머지 CAGE), 유지 비율 | 기술 (3l의 "뇌 형질·LDL·키에서 효과 정보 유지"가 큰 GWAS에서도 보이는지) |

- 기준 근거: N-H1·N-H2는 주 지도와 3j에서 쓴 검정과 기준을 그대로 쓴다. 표본이 커지면 SE가 줄어 검정력이 오른다. 따라서 이질성이 사라지면 원래 지도의 이질성이 작은 GWAS의 잡음 때문이었을 수 있다는 뜻이 된다.

## 읽는 규칙
- N-H1 유지 + N-H2 두 대비 유지 → 결과에 한 문단("더 큰 GWAS 다섯 개로 바꿔도 …"), 보충 표 하나. 초록 견고성 문장에 "and with larger GWAS for five traits"를 넣을지는 결과를 본 뒤 사용자가 정한다.
- 하나라도 "약화"·"반대" 또는 N-H1 미달 → 숨기지 않고 결과와 한계에 적는다. 어떤 형질이 바뀌었는지(N-H3·N-H4)로 설명한다.
- 주 지도는 원래 GWAS 그대로 둔다(이미 고정된 분석). 새 GWAS 결과는 강건성 분석으로만 보고한다.

## 한계 (미리 적음)
- 새 GWAS는 원래 참가자를 포함하므로 독립 검증이 아니다.
- UKB 포함 여부가 형질마다 다르다. 공동 jackknife가 공분산을 반영하지만, UKB를 뺀 판(키·양극성장애·LDL은 공개돼 있음)은 이번에 쓰지 않는다(필요하면 심사 때).
- 교육 연수·신경증·IBD·RA·AD는 바꾸지 않는다(교수님 목록의 다섯 형질만).
