# 실험 3b: 실험 3 S-LDSC 결과의 강건성과 주석 타당성 (2026-09-28, 결과 보기 전 고정)

## 목적
실험 3의 결과는 "AD 유전율이 Atlas 골수계 주석에만 농축된다"였다(골수계 τ\* +2.75, 나머지 맥락 귀무). 이 결과에 대한 심사 질문 세 가지에 답한다.
1. **대형 좌위 의존**: h²_obs가 0.026으로 작고, 상위 5 % SNP가 유전율의 64 %를 설명한다. BIN1 같은 소수의 게놈 전역 유의 좌위가 τ\*를 끌고 있는가?
2. **APOE 포함**: 실험 3에서 사전 명시했지만 실행하지 않은 부 분석이다.
3. **주석 타당성**: AD에서 뉴런·성상세포 주석이 귀무인 것이 "AD 유전율이 거기 없다"는 뜻인가, "주석이 원래 아무것도 못 잡는다"는 뜻인가? 골수계 주석은 다른 골수계 형질에서도 작동하는가?

## 사후성 명시
- 1(대형 좌위 제외)은 실험 3 결과를 본 뒤 정한 **사후 민감도 분석**이다. 결과를 보고 제안했으므로 확증 분석으로 보고하지 않는다.
- 2(APOE 포함)는 실험 3 프로토콜의 사전 명시 부 분석이다. 세부 실행 방법은 여기서 처음 정한다.
- 3(다른 형질)은 새 분석이다. 이 프로토콜을 쓰는 시점에 대조 형질 요약통계는 받기만 했고, 열어 보거나 분석하지 않았다.

## 공통 설정 (실험 3과 동일)
- 주석: 실험 3 x03이 만든 주석과 LD 점수를 그대로 쓴다. 다시 만들지 않는다.
  - 주 주석: ct5_<맥락> 5개(세포형 강도 상위 5 %)
  - 부 주석: mod_myeloid_CAGE, mod_myeloid_DNASE (실험 3 E3-H3 통과 주석)
- 모형: baselineLD v2.2(hg38) 조건부, --overlap-annot, --frqfile(MAF ≥ 5 %), HapMap3 no-MHC 가중치, 200 블록 jackknife
- 도구: brainvisa/ldscore 포크(실험 3 x04와 같은 호출)
- τ\* = τ · sd(주석, 흔한 SNP) · M_5_50 / h²_obs. 각 실행의 h²_obs를 쓴다.
- 동시 모형: ct5set(세포형 5개 동시). 차이의 SE는 part_delete로 계산한다(실험 3 E3-H2와 같은 방식).

## 분석 1: 대형 좌위 제외 (사후 민감도)
### 제외 영역 정의
- **R_gws**: Bellenguez stage I 전체 요약통계(GCST90027158, SNV)에서 p < 5 × 10⁻⁸인 SNP 각각에 ±1 Mb 구간을 잡고, 겹치는 구간을 합친다.
- **R_75**: 1e의 75 좌위(발견 50 `loci.csv` + 재현 25 `rep25_loci.csv`) 선도 SNP ±1 Mb
- **주 제외 영역 = R_gws ∪ R_75**. APOE 영역은 실험 3처럼 이미 빠져 있다.
- 부 제외 영역: BIN1 좌위(L001 선도 SNP rs6733839 ±1 Mb)만 제외
- 방법: 제외 영역의 SNP를 **회귀 SNP(요약통계)에서만** 뺀다. 주석과 LD 점수는 그대로 둔다(MHC 제외와 같은 표준 방식).

### 가설과 판정 (α 사전 고정)
| | 내용 | 검정 | α |
|---|---|---|---|
| **E3S-1** | 주 제외 후 ct5_myeloid τ\* > 0 | 단측 z | 0.05 |
| **E3S-2** | 주 제외 후 동시 모형 τ\*_골수계 − τ\*_뉴런 > 0 | 단측 z (part_delete) | 0.05 |

- 판정 문구
  - E3S-1 통과: "골수계 농축은 게놈 전역 유의 좌위 밖에서도 유지된다"
  - E3S-1 불통과: "골수계 농축은 알려진 대형 좌위에 기댄다". 논문의 핵심 주장을 "알려진 좌위 수준"으로 낮춘다.
- 기술: τ\*와 농축도의 원래 대비 비율, 부 주석 2개, BIN1만 제외한 결과

### jackknife 블록 영향 (기술)
- 실험 3 주 실행(ct5_myeloid 단일)의 블록 제거 값으로 블록 하나를 뺀 τ\*를 200개 계산한다.
- 보고: 최소·최대, τ\*를 가장 크게 낮추는 블록 5개와 그 게놈 구간
  - 회귀 SNP 순서를 재구성해 블록 경계를 복원한다. 재구성한 SNP 수가 로그의 회귀 SNP 수와 같은지 확인한다.
- 기준(기술): 어떤 블록 하나를 빼도 τ\* > 0인가

## 분석 2: APOE 포함 (사전 명시 부 분석)
- 요약통계: 실험 3과 같은 준비 과정에서 **APOE 제외만 빼고** 다시 munge한다.
- ldsc 기본 χ² 상한 max(0.001 N, 80)은 그대로 둔다. 이 상한 때문에 APOE 핵심 SNP는 회귀에서 빠진다. 빠진 SNP 수를 보고한다.
- 실행: ct5 5개 단일, ct5set 동시 모형, 부 주석 2개
- 판정 없음(기술). 실험 3 주 결과와 방향·크기를 비교한다.

## 분석 3: 다른 형질 대조 (주석 타당성)
### 형질 (결과 보기 전 고정)
| 역할 | 형질 | 출처 |
|---|---|---|
| 골수계 양성 대조 | 단핵구 수 | Vuckovic 2020, GCST90002393 (UKB 408,112명), 조화 파일 |
| 골수계 양성 대조 | 염증성 장질환(IBD) | PASS_IBD: Jostins 2012, N 34,652 (Price 연구실 sumstats_formatted) |
| 골수계 양성 대조 | 류마티스 관절염(RA) | PASS_Rheumatoid_Arthritis: Okada 2014 유럽계, N 약 37,681 |
| 뉴런 양성 대조 | 조현병(SCZ) | PASS_Schizophrenia: PGC 2014, N 70,100 |
| 뉴런 양성 대조 | 교육 연수(EA) | PASS_Years_of_Education2: Okbay 2016, N 328,917 |
| 기준(기대 없음) | 키 | PASS_Height1: Lango Allen 2010, N 약 131,547 |

- PASS 파일은 이미 LDSC 형식이라 그대로 쓴다(HapMap3, MHC 제외, 열: SNP·CHISQ·N·Z). rsID로 hg38 LD 점수와 맞춘다.
  - h² 추정에는 대립유전자 열이 필요 없다. PASS_IBD는 부호가 없지만 χ²만 쓰므로 문제없다.
- 단핵구 수는 조화 파일의 hm_rsid, hm_effect_allele, hm_other_allele, hm_beta, standard_error로 Z를 만든다. N은 408,112로 둔다. HapMap3 no-MHC SNP만 남기고 munge한다(실험 3과 같은 절차).
- 실행: 형질마다 ct5 5개 단일 + ct5set 동시 모형

### 가설과 판정
| | 내용 | α |
|---|---|---|
| **C-H1** 골수계 주석 타당성 | 단핵구 수, IBD, RA 각각에서 ct5_myeloid τ\* > 0 | 0.05/3 단측 |
| **C-H2** 뉴런 주석 타당성 | SCZ, EA 각각에서 ct5_neuron τ\* > 0 | 0.05/2 단측 |

- 판정에 따른 해석 (미리 고정)
  - **C-H2가 하나 이상 통과**: Atlas 뉴런 주석은 뉴런 형질의 유전율을 잡는다. 따라서 AD의 뉴런 귀무는 정보가 있는 음성이다.
  - **C-H2가 모두 불통과**: 뉴런 주석의 민감도를 보여 줄 수 없다. AD 뉴런 귀무는 "주석 한계일 수 있다"로 쓴다. E3-H2(골수계 > 뉴런)의 해석도 약해진다.
  - **C-H1이 하나 이상 통과**: 골수계 주석이 골수계 생물학을 잡는다는 근거가 된다.
  - **C-H1이 모두 불통과**: AD 골수계 결과를 주석의 일반 타당성으로 뒷받침할 수 없다. 논문에 한계로 적는다.
- 기술 (판정 없음)
  - 형질 × 맥락 τ\* 표와 히트맵
  - 뉴런 형질(SCZ, EA)에서 골수계 τ\*
  - 동시 모형 차이(골수계 − 뉴런)의 형질 간 비교
  - 성상세포·간·기타 조직 주석이 어떤 형질에서든 농축되는지
