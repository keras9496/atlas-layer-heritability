# 실험 3g: 역치 민감도 — 상위 0.1 % 예측만으로도 층위 지도가 나타나는가 (2026-10-11, 결과 보기 전 고정)

## 배경
- 설계안 v3 §6 필수 5번이다. 선행 연구 검토(`paper/reports/Atlas 유전율 지도 선행 연구.md`)에서 올렸다.
- **Drusinsky & Pollard 2026** (bioRxiv, doi:10.64898/2026.09.08.750172)
  - AlphaGenome의 **유전자 발현 예측**으로 fine-mapped eQTL을 주변의 비원인 SNV와 비교했다.
  - 대부분의 원인 변이에서 효과를 **광범위하게 과소추정**했고, 그래서 대부분의 좌위에서 fine-mapping에 실패했다.
  - 원인 1: 인핸서 활성에 대한 국소 효과를 잡지 못한다. 원인 2: 표적 유전자와 먼 변이일수록 과소추정이 많다(인핸서–유전자 연결 부족).
  - 반면 **가장 두드러진 상위 약 0.1 % 예측**은 원인 변이에 강하게 농축되었다. 방향이 맞고 모델 복제본 사이에서도 일관되었다. 저자는 "매우 강한 예측은 대체로 믿을 만하다"고 결론 내렸다.
- 우리 주석과의 관계
  - 우리 층위는 발현 점수가 아니라 변이 자리의 국소 점수다(CAGE·DNase 501 bp, H3K27ac 2,001 bp). 유전자 연결 문제는 직접 해당하지 않는다. 국소 활성 과소추정은 해당한다.
  - S-LDSC에서 과소추정은 원인 변이를 주석 밖으로 밀어내 농축을 **희석**한다(보수적). 그러나 층위마다 과소추정 정도가 다르면 층위 차이가 왜곡될 수 있다.
  - 예상 반론: "상위 5 % 이진 주석의 대부분은 믿을 수 없는 예측이다. 층위 지도는 그 잡음의 산물일 수 있다." 이 실험은 믿을 만하다고 한 상위 0.1 %만으로 같은 지도가 나오는지 본다.

## 사후성 명시
- 상위 5 % 결과(3f 1단계 시드 평균, 전체 트랙 T3all, 3단계 검증)는 모두 이미 보았다.
- 상위 0.1 · 0.5 · 1 % 주석과 그 S-LDSC 결과는 아직 만들지 않았다. 이 문서는 그 전에 고정한다.

## 주석 (u01)
- 칸: 3f와 같은 계통 5개(골수계, 뇌 조직, 림프계, 간, 결합조직) × 층위 3개(CAGE, DNase, H3K27ac)
- **트랙: 전체 트랙**. 3d L5_{g,m}과 같은 트랙 묶음이다.
  - 근거: 3f에서 전체 트랙 판(T3all)의 1위 층위가 11개 형질 모두에서 트랙 균형 재추출 시드 평균과 같았다.
  - 재추출 × 역치(주석 900개, 실행 약 660회)는 이번에 하지 않는다.
- 값: 칸 안 트랙의 |ALT − REF| 최댓값 → 대상 SNP 5,828,323개에서 백분위(`rank(pct=True)`, 동점은 평균 순위)
- **역치 q 세 가지**: 백분위 ≥ 1 − q
  - q = 0.1 % → `L0p1_{g}_{m}`
  - q = 0.5 % → `L0p5_{g}_{m}`
  - q = 1 % → `L1p0_{g}_{m}`
  - 5 % 참조는 3d `L5_{g}_{m}`을 그대로 쓴다.
- 주석은 15칸 × 3 = 45개다. 묶음 `G3_{q}_{g}` = [CAGE, DNASE, H3K27ac]는 15개다.
- MAF < 5 % 또는 Atlas 값이 없는 SNP는 0이다(3d와 같다). l2 호출도 3d·3f와 같다.
- **확인 (어긋나면 멈춘다)**: 같은 코드로 다시 만든 상위 5 % 주석의 sd가 3d `annot_sd_common.csv`의 L5_{g}_{m}과 같아야 한다(차이 < 10⁻⁹).
- 기술(형질 결과 아님)
  - 주석 크기: SNP 수와 비율
  - 같은 계통 안 층위 사이 Jaccard
  - 주석 SNP가 걸친 1 Mb 구간 수(소수 좌위에 몰렸는지)

## 모형 (u02; 순차)
- **G3_{q}** = baselineLD v2.2 + `G3_{q}_{g}` (3개 층위 동시). 형질의 계통 g는 3f와 같다.
  - 본 형질 11개: AD·단핵구 수 → 골수계 / 교육 연수·조현병·양극성장애·신경증·BMI → 뇌 조직 / IBD·RA → 림프계 / LDL → 간 / 키 → 결합조직
  - 검증 형질 3개: 골밀도 → 결합조직 / 호중구 수 → 골수계 / 총콜레스테롤 → 간
- 5 % 참조: 3f `T3all` 실행 결과(14개 형질 모두 있다)
- 공통 설정은 3f와 같다: --overlap-annot, --frqfile, HapMap3 no-MHC 가중치, 200 블록 jackknife
  - τ\* = τ · sd · M_5_50 / h²_obs
- 실행 수: 14 × 3 = 42회(회당 약 3분, 약 2시간)
- 시험: 3f의 Z를 섞은 가짜 형질로 골수계 3회. 형식 확인용이며 결과가 아니다.

## 통계량
- 3f v03과 같다. 단, 시드 평균 대신 **단일 실행 jackknife**를 쓴다.
  - 대비: c1 = CAGE − DNase, c2 = CAGE − H3K27ac, c3 = DNase − H3K27ac
  - SE와 공분산은 같은 실행의 200 블록 삭제값으로 구한다.
- 형질별 1위 층위 = τ\*가 가장 큰 층위. 1위와 2위의 대비 단측 p도 함께 적는다.

## 가설과 판정 (α 사전 고정; 주 판정은 q = 0.1 %)
| | 내용 | 판정 |
|---|---|---|
| **G-H1 (주)** | q = 0.1 %에서 층위 프로필이 형질마다 다르다. 본 형질 11개의 다변량 Cochran Q, d = (c1, c2), 자유도 20 | χ² p < 0.05 |
| **G-H2** | q = 0.1 %에서 1위 층위가 3f 1단계 시드 평균 1위와 같은 형질 수 | 11개 중 9개 이상, **그리고 키가 DNase** |
| G-H3 | q = 0.1 %에서 3f의 쌍 비교 L-H2a(AD 대 키, c1), L-H2b(뇌 형질 4개 대 키, c1), L-H2c(림프계 대 골수계, c2) | 각각 양측 α 0.05/3 |
| G-H4 | q = 0.1 %에서 3f의 V-H1: (호중구 수·총콜레스테롤 c1 가중 평균) − (골밀도 c1) > 0 | 단측 α 0.05 |

### 읽는 규칙 (q = 0.1 %)
- **"재현"**: G-H1 통과 **그리고** G-H2 충족
  - 쓸 문장: "층위 지도는 Drusinsky & Pollard가 믿을 만하다고 한 상위 0.1 % 예측만으로도 나타난다."
  - 본문은 상위 5 %를 유지하고, 역치 민감도를 보충 자료와 본문 한 문장으로 보고한다.
- **"방향만 재현"**: G-H2 충족, G-H1 불통과
  - 쓸 문장: "1위 층위는 같지만 상위 0.1 % 주석에서는 형질 간 차이를 검정할 검정력이 부족하다."
  - 함께 보고: 대비 SE가 5 % 대비 몇 배로 커졌는지(형질 11개 c1 SE 비의 중앙값)
- **"재현 안 됨"**: G-H2 불충족
  - 층위 지도는 역치에 의존한다고 쓴다. 바뀐 형질과 방향을 보고한다.
  - 본문 주장을 줄이고, 연속값 주석을 다음 단계로 둔다.
- G-H3·G-H4는 판정을 보조하는 기술이다. 중심 문장을 바꾸지 않는다.

### 기술 (판정 없음)
1. q = 0.5 %, 1 %, 5 %(T3all)에서도 같은 통계량(Q, 1위 층위, 쌍 비교, V-H1)을 보고한다. 역치에 따른 경향을 본다.
2. 형질별 1위 층위의 **농축**(Prop. h² / Prop. SNP)을 역치별로 보고한다. 엄격한 역치에서 농축이 커지면 상위 예측일수록 유전율을 더 많이 담는다는 뜻이다.
3. 검증 형질 3개의 1위 층위가 3f 예측 층위(골밀도 DNase, 호중구 수·총콜레스테롤 CAGE)와 같은지 역치별로 보고한다.
4. 주석 크기, 층위 간 Jaccard, 1 Mb 구간 수(u01)

## 한계 (미리 적음)
- 전체 트랙만 쓴다. 트랙 수 효과는 3f의 5 % 결과로만 걸러졌다.
- q = 0.1 %는 칸마다 약 5,800 SNP다. SE가 커지므로 G-H1 불통과는 검정력 부족일 수 있다. 그래서 "방향만 재현" 범주를 따로 둔다.
- 형질 사이 독립 가정과 계통 선택의 사후성은 3f와 같다.
- Drusinsky & Pollard의 결론은 eQTL fine-mapping에 대한 것이다. 상위 0.1 %가 S-LDSC 주석에서도 가장 믿을 만하다는 보장은 없다. 이 실험은 그 주장에 맞춰 범위를 좁혀 보는 민감도 분석이다.
