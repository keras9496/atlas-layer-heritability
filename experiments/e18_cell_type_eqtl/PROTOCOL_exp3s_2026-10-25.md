## 주석 (s01)
- **세포형 MaxCPP**(Hormozdiari 2018과 같은 정의): SNP마다 해당 묶음의 맥락·유전자 전체에서 SuSiE PIP의 최댓값(보고되지 않은 SNP = 0). 연속 주석, 값 범위 [0, 1].
- 다섯 묶음(Q5):

  | 주석 | 맥락 |
  |---|---|
  | Q_MIC | MiGA 미세아교 4부위 + ROSMAP 단일핵 미세아교(세 판) |
  | Q_NEU | ROSMAP 단일핵 흥분·억제 뉴런(세 판) |
  | Q_GLIA | ROSMAP 단일핵 성상세포·희소돌기세포·OPC(세 판) |
  | Q_BULK | bulk 뇌 8개(Knight-ADRC, MSBB 4, ROSMAP 3) |
  | Q_MONO | ROSMAP 단핵구 |

- SNV만 쓴다(indel 제외). 1000G EUR hg38 참조 SNP(지금 주석과 같은 bim)에 염색체·위치·두 대립유전자(방향 무관)로 맞춘다.
- LD 점수: 지금까지와 같은 l2 호출(`--ld-wind-cm 1`, thin annot, 염색체별).
- 확인(어긋나면 멈춘다)
  1. FunGen SNV 행 중 참조 SNP에 맞은 비율을 맥락별로 적는다. 50 % 미만인 맥락이 있으면 멈추고 원인을 적는다(위치 기준 차이 의심).
  2. 값 범위 [0, 1].
  3. 같은 코드로 GTEx MaxCPP를 다시 만들지는 않는다. 대신 기준선 GTEx_eQTL_MaxCPP와 Q5의 상관을 기술로 적는다.
- 기술: 묶음별 MaxCPP > 0, > 0.1, > 0.5인 SNP 수; 기준선을 뺀 LD 점수에서 효과 3층위·활성도 3층위와의 편상관과 VIF(3l·3p와 같은 계산).

## 모형 (s02; 계통은 주 지도와 같다)
설정은 3j와 같다: baselineLD v2.2, 정렬 블록 200개, 같은 실행기.

| 모형 | 주석 | 비교 대상 |
|---|---|---|
| **EQ** | 효과 L5_{g} 3층위(3d 전체 트랙) + Q5 | E(3j T3all) |
| **EAQ** | 효과 L5_{g} 3층위 + 이진 활성도 A5_{g} 3층위(3l) + Q5 | EA(3l) |

- 형질: 원래 GWAS 14개(지도 11 + 검증 3) + 3n 새 GWAS 5개 + 3r 새 AD(N_AD) = 20개 × 2 = **40회**.
- 확인 단계(dry): 가짜 형질(3j FAKE1)로 주석 수(EQ 97 + 8, EAQ 97 + 11)와 형식만 확인한다(결과 아님).

## 가설과 판정 (α 사전 고정)
| | 내용 | 판정 |
|---|---|---|
| **S-H1 (주)** | AD(골수계)와 뇌 조직 형질 5개(교육 연수, 조현병, 양극성장애, 신경증, BMI): **EQ에서 자기 층위(CAGE) 효과 τ\* > 0**(단측, 6개 BH). E에서는 6/6이 유의했다 | FDR < 0.05인 형질 수: **5–6 → "세포형 eQTL을 넘어 유지"**, 3–4 → "부분", 0–2 → "대부분 세포형 eQTL로 설명". 유지 비율(EQ/E)의 중앙값을 함께 적는다 |
| **S-H2 (주, AD)** | AD의 정보는 활성도에 있었다(3l). **EAQ에서 AD 골수계 CAGE 활성도 τ\* > 0**(단측 α 0.05) | P < 0.05 → "AD의 골수계 전사 개시 활성 위치 정보는 미세아교·단핵구·뇌 세포형 eQTL을 넘는다"; 아니면 "세포형 eQTL과 구분되지 않는다" |
| S-H3 | 지도 11 + 검증 3: EQ·EAQ에서 자기 층위 효과 τ\*와 유지 비율; EQ에서 층위 지도의 Q(지도 11개, 공동 jackknife), 사전 대비 3개, 검증 대비 | 기술 |
| S-H4 | Q5 각 주석의 τ\*(형질별; 예: AD의 Q_MIC, 뇌 형질의 Q_NEU) — 기준선 GTEx MaxCPP와 예측 주석을 함께 넣은 조건부 값 | 기술 |
| S-H5 | 더 큰 GWAS 6개(3n 5 + N_AD): S-H1·S-H2와 같은 값 | 기술 |

- 기준 근거
  - S-H1의 대상은 세포형 eQTL이 겹치는 계통(뇌 조직, 골수계)이다.
  - 다른 형질(단핵구 수, IBD, RA, LDL, 키; 검증 3개)은 세포형 eQTL과 관련이 적으므로 S-H3에서 기술로만 본다.
  - 세 범주 경계(5–6 / 3–4 / 0–2)는 E에서 6/6이 유의했다는 점을 기준으로 정했다.

## 읽는 규칙
- **S-H1 "유지"** → 원고 eQTL 절(R5)에 한 문장을 넣는다: "Predicted annotations remained informative after conditioning on fine-mapped eQTLs from microglia and sorted brain cell types". AD 문단에는 S-H2를 적는다.
- **"부분" 또는 "대부분 설명"** → 숨기지 않는다. 결과와 토론의 "eQTL을 넘는다" 주장을 "조직 eQTL을 넘는다"로 좁힌다. 어떤 형질에서 줄었는지(S-H3)와 어느 묶음이 흡수했는지(S-H4)로 설명한다.
- 3s는 "세포형 eQTL을 넘는가"만 다룬다. "시작점 선택인가 접근성인가"는 답하지 않는다. 미세아교에서 전사 개시를 직접 잰 QTL이 없기 때문이다(검토서 3.2).

## 한계 (미리 적음)
- 단일핵 미세아교 eQTL은 세포 수가 적어 검정력이 낮다. 그래서 Q_MIC가 듬성듬성하다. MiGA 미세아교는 표본이 약 100명 수준이다.
- MaxCPP는 정밀지도화 품질(표본 LD, 창 크기; FunGen은 TAD로 넓힌 창)에 의존한다.
- FunGen-xQTL은 preprint 자원이다. 세 단일핵 판은 같은 ROSMAP 참가자를 일부 공유한다. MaxCPP는 최댓값이라 중복 계산은 없다.
- S-LDSC는 게놈 전역 평균이다. 질문의 "추가 정보를 주는 영역 찾기"는 좌위 단위 연구(후속)에서 한다.
- AD의 예측 계통은 골수계(단핵구·대식세포 트랙)이고, 조건화 eQTL은 미세아교다. 같은 계열이지만 같은 세포는 아니다.
