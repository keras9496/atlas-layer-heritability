# 실험 3f: 형질별 조절 층위 지도 — 유전율을 운반하는 층위는 형질마다 다른가 (2026-10-09, 결과 보기 전 고정)

## 배경과 사용자 결정 (2026-10-09)
- 지도 논문의 메시지는 "CAGE가 이긴다"가 아니라 다음이다. **형질마다 유전율을 운반하는 조직과 조절 층위가 다르다.** 예: 키는 결합조직 DNase형, AD는 골수계 CAGE형.
- 지금까지(3d D-H3, 3d-A, 3e)는 CAGE 중심으로 설계되었다. 이 실험은 층위 차이 자체를 주 검정으로 둔다.
- 사용자가 정한 구성
  1. 주 검정: 형질 × 층위 상호작용(Cochran Q)과 미리 정한 쌍 비교
  2. 트랙 재추출 20회로 트랙 수 효과를 걷어 낸다.
  3. 검증: 가장 확실하게 예측할 수 있는 형질 2–3개만 고른다. **결과를 미리 예측해 고정한 뒤** 실행한다.

## 사후성 명시
- 1–2단계의 가설(키 = DNase형, 골수계·간 = CAGE형, 림프계 = H3K27ac형 가능성)은 **같은 GWAS의 3d 결과(D2, D2k)를 보고 세운 것**이다.
  - 따라서 1–2단계는 독립 확인이 아니다. 트랙 균형을 맞춘 주석으로 미리 정한 검정을 다시 해 보는 강건성 분석이다.
- 독립 확인은 3단계(새 형질, 사전 예측)의 몫이다.
- 프로토콜을 쓰기 전에 본 것
  - 3d D2·D2k 층위 프로필, 3d-A, 3e 결과
  - 3d `y04_A_diffs.csv`로 계산해 본 사후 예시: AD 대 키의 (DNase − CAGE) 차이, z ≈ 2.0
  - 검증 형질 요약통계의 존재 여부(GWAS Catalog 메타데이터만)

## 층위와 계통
- 층위는 3개다: **CAGE**(전사 시작), **DNase**(접근성), **H3K27ac**(활성 인핸서·프로모터 크로마틴). 3e의 실측 세 층위와 같다.
  - H3K4me1·H3K4me3는 H3K27ac와 공선성이 크다(3d D2에서 H3K4me1 τ\*가 대부분 음수였다). RNA는 거의 비어 있었다. 그래서 주 모형에서 뺀다.
  - 6개 층위 동시 모형(3d D2·D2k)은 기술 자료로만 인용한다.
- 형질 × 계통은 3d-A·3e와 같다(형질마다 계통 하나).
  - AD·단핵구 수 → 골수계
  - 교육 연수·조현병·양극성장애·신경증·BMI → 뇌 조직
  - IBD·RA → 림프계
  - LDL → 간
  - 키 → 결합조직

## 1단계 주석: 트랙 균형 재추출 (v01)
- **단위**
  - DNase·H3K27ac: 트랙 하나가 단위다.
  - CAGE: biosample 하나(가닥 + / − 트랙 2개)가 단위다. 키에서 가닥 표시를 뗀 것(예: `hCAGE UBERON:0000955`)이 하나의 단위다.
  - 이유: CAGE는 biosample마다 가닥 트랙이 둘이다. 트랙 단위로 3개를 뽑으면 다른 층위와 biosample 수가 맞지 않는다. 3d L5k는 트랙 단위로 뽑았는데, 이 점을 바로잡는다.
- **재추출**
  - 계통 g, 층위 m마다 단위 k = 3개를 비복원으로 뽑는다. 단위가 3개 이하인 칸은 모두 쓴다.
  - 해당 칸: 간 CAGE(2), 골수계 H3K27ac(3), 간 H3K27ac(3)
  - 시드는 20개다. `numpy.random.default_rng(20261009)` 하나로 시드 → 계통 → 층위 순서로 뽑는다.
- **주석**: 뽑힌 트랙의 |ALT − REF| 최댓값 → 대상 SNP 전체에서 백분위 → 상위 5 %. 3d y03과 같은 방식이다.
  - 계통은 5개(골수계, 뇌 조직, 림프계, 간, 결합조직)다. 칸 15개 × 시드 20개 = 주석 300개.
  - 묶음 T3_{s}_{g}(3개 층위)는 100개다.
- 참조용 전체 트랙 판은 3d의 L5_{g,m}을 그대로 묶어 쓴다(T3all_g).

## 1단계 모형 (v02; 순차)
- **T3** = baselineLD + L5r_{s,g,CAGE} + L5r_{s,g,DNASE} + L5r_{s,g,H3K27ac} (3개 층위 동시)
  - 실행 수: 형질 11 × 시드 20 = 220회
- **T3all** = 같은 형식에 전체 트랙 주석 (11회, 참조)
- 3d·3e와 같은 공통 설정: baselineLD v2.2, --overlap-annot, --frqfile, HapMap3 no-MHC 가중치, 200 블록 jackknife
  - τ\* = τ · sd · M_5_50 / h²_obs
- 모두 231회다. 회당 약 3분이므로 약 12시간이다.

## 통계량
- **형질 안 대비** (τ\* 척도): c1 = CAGE − DNase, c2 = CAGE − H3K27ac, c3 = DNase − H3K27ac (= c2 − c1)
- **시드 평균**: c̄ = (1/20) Σ_s c_s
  - jackknife 삭제값도 시드마다 같은 블록끼리 평균한다. 같은 형질이면 회귀 SNP와 200 블록 경계가 시드 사이에 같다.
  - SE = √((B−1)/B Σ_b (c̄_(b) − c̄_(·))²), B = 200
  - 2차원 벡터 d = (c1, c2)의 공분산도 같은 방식으로 구한다.
- 형질 사이에는 독립을 가정한다(아래 한계).

## 1단계 가설과 판정 (α 사전 고정)
| | 내용 | 판정 |
|---|---|---|
| **L-H1 (주)** | 층위 프로필이 형질마다 다르다. 다변량 Cochran Q: Q = Σ_i (d_i − d̄)ᵀ Σ_i⁻¹ (d_i − d̄), d̄는 Σ_i⁻¹ 가중 평균, 자유도 2(K − 1) = 20 | χ² p < 0.05 |
| **L-H2a** | AD 대 키: c1(CAGE − DNase)이 다르다 | 양측, α 0.05/3 |
| **L-H2b** | 뇌 형질(교육 연수·조현병·양극성장애·신경증, 역분산 가중 평균) 대 키: c1이 다르다 | 양측, α 0.05/3 |
| **L-H2c** | 림프계(IBD·RA 가중 평균) 대 골수계(AD·단핵구 수 가중 평균): c2(CAGE − H3K27ac)가 다르다 | 양측, α 0.05/3 |

- 차이의 SE는 √(SE_A² + SE_B²)다. 묶음 평균의 SE는 √(1/Σw)다.

### 읽는 규칙
- **L-H1 p < 0.05**: "유전율을 운반하는 조절 층위는 형질마다 다르다." 지도 논문의 중심 문장으로 쓴다.
  - L-H2a–c 중 유의한 쌍으로 구체적인 대비를 예시한다.
- **L-H1 p ≥ 0.05**: "트랙 균형을 맞추면 형질 간 층위 차이는 검출되지 않는다." 층위 지도를 중심 주장으로 쓰지 않는다. 3단계는 그대로 실행하되 기술로 보고한다.

### 기술 (판정 없음)
1. 대비별 단변량 Cochran Q 3개(자유도 10)
2. 형질별 시드 평균 τ\*(3개 층위), 그리고 시드 20개 중 각 층위가 1위인 횟수
3. **층위형 분류** (지도 표기 규칙)
   - **"확정 X형"**: 층위 X가 다음 세 조건을 모두 만족할 때
     - 시드 평균 τ\*가 가장 크다.
     - 시드 20개 중 15개 이상에서 1위다.
     - 2위 층위와의 시드 평균 대비가 단측 p < 0.05다.
   - 그 밖에는 "미정"으로 쓰고, 최빈 1위 층위와 그 횟수를 함께 적는다.
4. 전체 트랙 판(T3all)과 시드 평균 판의 1위 층위 비교(트랙 수 효과)

### 예측 규칙 (지금 고정)

- 지금 지도 기준의 예상(참고): V1 = DNase형, V2 = CAGE형, V3 = CAGE형
- 1단계가 끝나면 규칙에 따라 기계적으로 정해진 예측을 실행 전에 이 문서에 적는다.

### 검증 모형

- **T3 층위**: 예측 계통에서 시드 20개를 쓴다(1단계 주석을 그대로 쓴다). 형질마다 20회, 참조 T3all 1회.

### 검증 가설 (α 사전 고정)
| | 내용 | 판정 |
|---|---|---|
| **V-H1 (주)** | 형질 사이의 층위 대비가 예측 방향으로 다르다: (CAGE형으로 예측된 검증 형질의 c1 가중 평균) − (DNase형으로 예측된 검증 형질의 c1) > 0 | 단측 α 0.05 |
| V-H2 | 형질마다 예측 계통의 M1 τ\* > 0 | 형질마다 단측 α 0.05 |
| V-H3 | 형질마다 예측 층위형 | 예측 층위와 나머지 두 층위의 시드 평균 대비가 모두 단측 p < 0.05이면 일치(교집합–합집합 검정) |

- V-H1은 CAGE형 예측 형질과 DNase형 예측 형질이 각각 하나 이상 있을 때만 판정한다. 1단계 분류가 바뀌면 같은 규칙으로 대비 방향을 다시 정한다. 대비할 두 형이 없으면 기술로 보고한다.
- 기술: 형질마다 12개 계통 중 예측 계통의 순위, 시드 20개 중 예측 층위가 1위인 횟수

## 한계 (미리 적음)
- **형질 사이의 독립 가정**: UKB가 겹치는 형질이 있다. 1단계에서는 교육 연수·신경증·단핵구 수·AD(UKB 대리)가, 3단계에서는 V1–V3과 단핵구 수가 겹친다.
  - 표본이 겹치면 추정 오차가 양의 상관을 가진다. 그러면 차이의 분산을 과대 추정하므로 Q 검정과 쌍 비교는 보수적이다.
  - 미리 정한 쌍 비교(AD 대 키, 뇌 대 키, 림프계 대 골수계)는 대부분 표본이 독립인 조합이다.
- **시드 평균 jackknife**: 시드 사이의 주석 변동은 분산에 들어가지 않는다. 고정된 20개 시드 묶음에 대한 추론이다. 시드 사이의 변동은 1위 횟수로 따로 보고한다.
- **계통 선택은 사후다**(3c).
- V2는 유사 형질과 같은 표본이다. 그래서 V2의 일치는 V1·V3보다 약한 근거다.
